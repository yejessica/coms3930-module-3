# Co-op Maze Game
## Preview
![](module3-preview.gif)
## Required Materials
- 2 ESP32s
## Recreation
1. Clone this repository.
2. Open file `coms3930-module-3.ino` in the Arduino IDE.
3. Near the top of the file, at the line that begins with `#define PLAYER_ID`, ensure that one ESP32 is set to `1` and the other is set to `0`.
4. Run the code on both ESP32s.
5. Happy maze navigating!
